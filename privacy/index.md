# Website privacy

How the ABLITERATED.cloud static website, hosting and Signal contact work.

## What this website does

This site serves public HTML, CSS, images, Markdown and JSON. The current website contains no analytics script, advertising tracker, contact form, account sign-in or payment checkout. Reading the pages does not require an account. There is no inference chat box that sends your prompts from this website.

## Hosting requests

The website is hosted on GitHub Pages. Visiting it sends ordinary HTTP requests to the hosting infrastructure, including your IP address, user agent and requested URLs. Hosting providers may process request logs under their own policies. We do not promise that accessing a public website creates no logs.

## Contact through Signal

Clicking the contact link opens Signal, a separate service. Messages you choose to send are used to discuss your enquiry and any agreed setup work. Do not send access credentials before agreeing a secure access method. Contact us on Signal with questions about information you shared.

## Your model deployment

The privacy and logging behavior of a self-hosted AI endpoint depends on the model runtime, your apps and the GPU host. This website does not provide a blanket privacy guarantee for a separately configured server. Discuss access controls and logging as part of the setup.
