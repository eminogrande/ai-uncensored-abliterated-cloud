About ABLITERATED.cloud

Intelligence, freed.

ABLITERATED.cloud helps people run uncensored and abliterated language models on infrastructure they control. Emin Mahrt maintains the project. We publish model research and provide human-assisted cloud GPU setup, self-hosting and app or LLM router integration.

Open code, practical help

Our current documented cloud workflow uses Vast.ai and llama.cpp with private SSH access. You can read the source and operating guide before asking for help. Setup scope, tests and assistance pricing are agreed through Signal. This is not an instant public API-key service.

How we report on models

The model blog links primary sources and preserves publication dates, model licenses and the context behind reported benchmarks. A model appearing in an article does not mean we host it or have independently validated every publisher claim. Abliteration reduces refusal behavior; it does not guarantee every answer.

Who owns the software

Project-owned website code and documentation use MIT. Model weights and third-party dependencies keep their own licenses. Cloud compute and setup work are separate from the free code.
