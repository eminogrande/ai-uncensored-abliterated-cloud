THE CURRENT WORKFLOW

Manual. Private. Deliberate.

  1. Start on Vast.ai

    The operator checks the instance, disk, current quote and spending scope, then starts it explicitly. This website cannot start a GPU.

  2. Connect over SSH

    llama.cpp stays on localhost:8080. Use an operator-controlled SSH tunnel and inspect the actual loaded model before evaluating it.

  3. Stop and verify

    Stop manually and read back the instance state. No automatic idle shutdown is proven. Stopping retains disk and ongoing storage charges; it is not deletion.

EVIDENCE, NOT A LEADERBOARD

What is not established.

  • Long-context quality: 262144 is a configured context limit, not validation that long inputs work reliably.
  • A best model or a speed promise: old runs used different artifacts, settings and tests. They do not establish a current winner or comparable performance.
  • Zero refusals: abliteration aims to reduce refusal behavior. A publisher’s result on one test set is not a general guarantee of behavior, capability or correctness.
  • A public service: no public inference, billing, customer accounts, inference OAuth or live MCP service is offered here.

Modal is retired and not used: its cost did not fit this experiment. Vast.ai is the only current operating path. Archived documentation and release notes describe history, not available products.
