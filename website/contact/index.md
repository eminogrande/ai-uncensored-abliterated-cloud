# Contact ABLITERATED.cloud

Talk on Signal about uncensored AI cloud GPU rentals, self-hosting or connecting your LLM app.

## Talk to a person

Send us a message on Signal to discuss your model, a cloud GPU rental, self-hosting on your own hardware, or connecting an app to an OpenAI-compatible LLM endpoint. The Signal link below is our setup-enquiry channel.

## What to include

A model repository link, the app or coding client you want to use, and your hardware or GPU budget are enough to start. Tell us what a successful test looks like for your use case. If you already have a rented server, share its specifications, not its password.

## Before work starts

We agree the scope, assistance price and compute spending separately. A message is an enquiry, not a completed order or a promise of instant model availability. Do not send API keys, private keys, passwords or payment credentials in an initial enquiry.

## Prefer to build it yourself?

The source repository and Vast.ai operating guide are public. Start there, then use Signal if you want help with model fit, private access, client configuration or testing.
