# ABLITERATED.cloud website v0.8.2

This visual release replaces the bounded brain silhouette with a soft pastel
synapse field spanning the complete hero.

## Full-hero synapses

The deterministic 1,280-node Canvas network now fills the hero on desktop and
mobile. Brain contours, cortical folds and the static brain fallback are
removed; pointer interaction, viewport pausing and reduced-motion support stay
intact.

## Pastel palette

The network uses pastel pink, blue, green, peach and violet for both resting
connections and pointer-activated glow. A light left-to-right wash preserves
copy contrast without hiding the field.

## Runtime safety

This is a static website release. It does not import or deploy Modal runtime
definitions, wake a model, or start a GPU.
